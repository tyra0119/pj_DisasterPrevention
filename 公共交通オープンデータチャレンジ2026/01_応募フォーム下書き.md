## 概要（短い版・100 字程度）

地震のあと、鉄道会社が「運転再開の見込みは立っていません」としか言えない数時間に、
訪日外国人へ「待つか、今夜の寝場所を確保するか」を決める数字を出す Web アプリ。

英語: After an earthquake, when every railway says "no estimate for resumption",
Move or Wait gives visitors to Japan a number — so they can decide now whether to wait or to book a bed for tonight.

## 概要（長い版・400〜600 字）

大きな地震のあと、鉄道各社は点検が終わるまで「運転再開の見込みは立っていません」と案内します。
これは方針ではなく、点検内容で復旧時間が大きく変わるため数字が出せないからです。
2026 年 8 月 23 日の茨城県南部の地震（最大震度 5 弱）では、深夜 2 時の発生から始発の運転見合わせを経て、
発生 4 時間後の 6 時 15 分になっても再開見込みが出ませんでした。

この数時間に一番困るのが訪日外国人です。日本語の案内が読めず、「点検」が何時間を意味するか知らず、
駅周辺のホテルが地震のあと数時間で埋まることも知りません。1 時間目に決めるか 4 時間目に決めるかで結果が変わります。

Move or Wait は、この「見込みは立っていません」に数字を与えます。
気象庁の震度分布を全国 596 路線・約 1 万駅に重ね、鉄道の運転規制基準（震度 4 → 注意運転点検、
震度 5 弱 → 徒歩点検 6.0 分/km、震度 6 弱以上 → 当面不通）に基づく既往研究の推定式で、
路線ごとの「再開までの幅」を出します。それを「今夜のうちに戻れる見込み / 今夜は電車で戻れないかもしれない」
という決断の形にし、事前登録した宿と出国便について表示します。

公共交通オープンデータセンターの運転系統・駅データで、震度の当たった線路を旅客が知る運転系統
（山手線・中央線快速など）に組み替え、運行情報 API で「平常」が出た系統は推定を取り下げます。
推定を「終わらせる」手段として運行情報を使うのが特徴です。

あわせて、現在地の住所（駅員やタクシーに画面を見せて伝えられる）、帰宅困難者向け一時滞在施設（東京都）、
指定緊急避難場所（国土地理院）を地図で示します。
サーバもビルドも持たない静的サイトで、Service Worker により圏外でも最後の判定を表示します。

## 特徴・アピールポイント（箇条書き）

- **他に無い数字。** 「再開まで 51 分〜4 時間 26 分・11:32〜15:07 ごろ」を路線ごとに出す。鉄道会社も報道も出さない
- **決断の形で出す。** 震度でも分数でもなく「今夜のうちに戻れる見込み」「宿を取るなら早い方がいい」。終電と便の出発時刻から逆算
- **運行情報で推定を終わらせる。** ODPT `odpt:TrainInformation` が「平常」なら推定を捨てて ✓平常。「見合わせ」なら裏付けとして表示。予報文・否定文は現在の事実として読まない
- **運転系統への組み替え。** 国土数値情報の「線路名称」（山手線 = 品川〜田端の 17 駅）を、ODPT の `odpt:Railway` / `odpt:Station` で旅客が知る系統に合成。190 系統・駅被覆 98.2%
- **4 言語**（日本語・英語・中文・한국어）。震源名は気象庁の英語名を使用
- **事前登録 URL。** 宿・出国便・言語をクエリに持たせたリンクを、旅行会社や宿が客に配れる
- **鍵なし・サーバなし。** GitHub Pages の静的配信。地震直後の輻輳時でも配信側が落ちにくい
- 現在地は住所で表示（言葉が通じなくても画面を見せれば伝わる）。一時滞在施設と指定緊急避難場所を同じ地図に

## 利用した公共交通オープンデータ

公共交通オープンデータセンター（api.odpt.org / api-challenge.odpt.org）

- `odpt:Railway`, `odpt:Station`, `odpt:Operator` … 運転系統と駅の対応表の生成
- `odpt:TrainInformation` … 運行情報。推定の裏付け・取り下げ

詳細は `03_利用データと出典.md`。

## 利用したその他のデータ

- 気象庁 地震情報（bosai JSON）、P2P地震情報 API v2
- 気象庁 震度観測点一覧表
- 国土数値情報 鉄道データ N02-25（CC BY 4.0）
- 国土地理院 指定緊急避難場所データ、逆ジオコーダ、地理院タイル
- 東京都オープンデータカタログ 一時滞在施設（都・品川区）
- 高浜・翠川 (2011)「地震時の鉄道運休時間の推定方法」日本地震工学会論文集 11(2)

## 開発に使った技術

HTML / CSS / JavaScript (ES modules, 依存ライブラリなし)、Service Worker、GitHub Pages。
データ生成は Node.js スクリプト（`npm run data:build`）。地図タイル描画は自前実装。

## 想定利用者

訪日外国人旅行者。および宿泊施設・旅行会社・空港のスタッフ（客に設定付きリンクを配る側）。
