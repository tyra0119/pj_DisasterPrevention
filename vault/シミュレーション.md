# シミュレーション

[[DisasterPrevention]] の利用想定と、実際に遭遇したときの動きが合っているかを
時系列で追った。2026-09-06。コードの実際の挙動を読んで書いたもので、願望ではない。

## 場面

韓国からの旅行者。宿は新宿。いま浅草で観光中。明朝 10:40 成田発。日本語は読めない。
平日 15:30、千葉県北西部 M6.0、東京で震度5弱。

## 時系列と、直す前のアプリ

| 時刻 | 起きること | アプリ | |
|---|---|---|---|
| 15:30 | 強い揺れ | 開いていない。プッシュ無し | 設計どおり |
| 15:32 | 電車が止まる。駅の案内は日本語。アプリを開く | 震度速報（区域単位）しか無い | |
| | | 全地点 unknown → 行の印は「不明」なのに**見出しは「平常どおり」** | **致命的** |
| 15:40 | 観測点単位の震度が届く | 「止まっている見込み・1〜5時間」「今夜のうちに戻れる見込み」 | 正しい |
| 15:45 | どこで待つか | 一時滞在施設が出る | 正しい |
| 17:10 | 震度4 の余震 | 「最新」を取るので余震に切り替わり**「遅れ・30分」に格下げ** | **誤り** |
| 18:00 | 実際に運転再開 | 知る術が無い。**20:30 まで「止まっている」と言い続ける** | 構造的な穴 |
| 20:45 | 推定の上限を過ぎる | 「点検時間は過ぎています」— でも行動は**「そのまま待つ」のまま** | 文言の誤り |

ほかに、初回に場所未設定で開くと**地震の重さが見出しに出ない**。
飛行機に間に合わないとき、**バス・タクシーに一切触れない**。

## 直したこと

**速報段階を作った。** 観測点単位の震度が来るまでは、場所ごとの推定を出さない。
「強い揺れを観測 — 詳細を待っています／近くの電車は止まっている可能性が高い／
まず動かず、安全を確保」。琥珀の帯、行の印は「速報」。
強い地震の直後に「平常」と出るのは最悪の誤りで、これが一番大きい修正。

**余震で判定を下げない。** 窓の中で最も強い地震を取る。同じ強さなら新しい方。
本震の点検はまだ続いているのに、小さい余震で「遅れ・30分」に格下げしていた。

**推定の上限を過ぎたら言い方を変える。** 「再開しているかもしれません／
駅の案内か運行情報で確認してから動いてください」。帯は琥珀、印は「要確認」。
再開していれば、「待て」と言い続けた分だけ無駄に足止めしている。

**未設定でも「地震が発生しました」と見せる。** 何が起きたかは場所を教える前に分かるべき。

**間に合わないときは鉄道以外に触れる。** 「空港バスやタクシーは動いていることがあります」。
震度5弱程度なら道路は通れることが多い。

## 直せていないこと

**実際の再開を知る術が無い。** 推定はあくまで推定で、17:00 に再開していても
20:30 まで「止まっている」と言う。逆向きの失敗で、不要な宿を取らせる。

ここが **ODPT 運行情報の出番**。[[ゴール]] で優先度を下げたが、
理由が変わった。見出しに使うためではなく、**推定を終わらせるため**に要る。
「運行情報が『平常』なら推定を捨てる」— それだけで 18:00〜20:30 の穴が埋まる。
実行時の鍵の問題は残る。→ [[宿題]]

## 2 回目（直した後に追い直した）

同じ場面をもう一度。今度は前回見ていなかった経路も足した。

| 時刻 | 起きること | アプリ | |
|---|---|---|---|
| 朝 | 共有リンクで開き、宿と便を入れる | | |

| 15:32 | 速報段階 | 「強い揺れを観測 — 詳細を待っています」琥珀 | 直った |
| 15:40 | 観測点単位 | 「止まっている見込み」「今夜のうちに戻れる見込み」 | 正しい |

| 翌 10:40 | 出発 | **端末の時間帯で解釈**。出発国の時間のままなら 17 時間ずれる | **壊れていた** |

さらに、**関西以西で駅検索が当たらない**（Kyoto 0 件）。ODPT の駅は関東に偏っている。
現在地取得があれば済むが、位置情報を拒否した人は詰む。

**震度6弱以上が 12 時間で窓から落ちる**。翌朝に「平常どおり」と出る。
復旧に日単位かかる領域なのに。

### 直した

- **設定を端末にも残す。** URL から読んだ時点で保存する。操作したときだけ保存していたら、
  リンクから開いてそのまま閉じた人には何も残らない。過去の地震やテスト表示は残さない
- **出発時刻は日本時間に決め打つ。** 日本の空港を発つ便なので端末の時間帯は関係ない
- **駅検索を全国に広げた。** 英語名で当たらなければ N02 の全駅を日本語で見る。
  京都・博多が引けるようになった。英語では引けないままだが、漢字が読める人と
  駅名を書き写せる人には届く
- **震度6弱以上は 48 時間残す。** 再開を知る術が無いあいだは長めが安全側

### まだ直せていない

- **英語で関西以西の駅が引けない。** ローマ字の駅名データが無い。現在地取得が頼り
- ~~別々の地域で同時に地震が起きたときは片方しか見ない~~ → 合成した。
  観測点ごとに最も強い震度を取り、その震度を与えた地震の発生時刻を観測点に持たせる。
  点検の起点は地震ごとに正しく数えられる。震源の行に「ほか N 件」と出る
- ~~実際の再開を知る術が無い~~ → [[運行情報で推定を終わらせる]]。
  コードは入れた。中継先を置くのは本人

## 分かったこと

**テストシナリオは「発生 15〜55 分後」しか無かった。** 速報段階（3 分後）と
推定を過ぎた後（7 時間後）を足した。時間軸の両端で壊れていたのに、
真ん中だけ見て「動く」と思っていた。

**2 回目は「地震の前」と「アプリを開き直す」を足して壊れた。**
地震のことばかり考えていて、朝に設定して昼に開き直す、という当たり前の流れを
追っていなかった。時系列は地震の前から始めるべきだった。
