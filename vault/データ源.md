# データ源

[[DisasterPrevention]] が使うデータと、それぞれの制約。
ファイルサイズや生成手順は `NOTES.md` にある。

## P2P地震情報 API v2 — 一次

`api.p2pquake.net/v2/history?codes=551`

鍵不要・CORS 開放。静的ホスティングのままブラウザから直接叩ける。
`points[]` は `(pref, addr)` の文字列しか持たず座標がないので、
観測点マスタで引き直す必要がある。

- `isArea: false` … 観測点単位（詳細情報）
- `isArea: true` … 細分区域単位（速報）

## 気象庁 bosai JSON — 二次

`www.jma.go.jp/bosai/quake/data/list.json` と各詳細 JSON

**想定外の発見。** 気象庁が自サイト用に出しているもので、XML と同じ内容が
JSON 化済み・鍵なし・CORS 開放・`max-age=60`。`en_ttl` / `en_anm`（英語の震源名）まで入っている。

「将来的に気象庁 XML へ」は XML パーサを書かずに今すぐ到達できる。
P2P を一次にしつつ、これを突き合わせ用の二次系に置くのが素直。
訪日外国人向けなので英語の震源名がそのまま使えるのも大きい。

## 気象庁 震度観測点一覧表 — 座標辞書

観測点 4,360 点。`(pref, 観測点名)` はマスタ内で一意なので、
P2P の `(pref, addr)` をそのままキーにできる。実データ 6,016 点で欠落ゼロ。

細分区域 188 はポリゴンを配らず、所属観測点の重心と bbox で代用した。
速報は区域単位でしか来ないので「区域のどこか」が示せれば足りる。

**取得は公開ミラー経由。** 一次情報は気象庁の一覧表そのものなので、
ミラーが止まったら CSV から作り直せばよい。
https://www.data.jma.go.jp/eqev/data/kyoshin/jma-shindo.html

## 国土数値情報 鉄道データ N02-25 — 駅・路線

**CC BY 4.0。** 生成物を Pages に同梱して配れる。出典表示は要る。
ZIP でしか配られないので、依存を増やさないよう最小の ZIP 展開を自前で書いた。

**路線名は「線路名称」であって「運転系統」ではない。**
N02 の山手線は品川〜新宿〜田端の 17 駅しかない。東京〜品川は東海道線、
田端〜東京は東北線として別レコード。乗客が思う一周ではないし、
ODPT の運行情報は運転系統単位で来る。→ [[宿題]]

事業者名と路線名が入れ替わった行がある（`えちぜん鉄道 / 三国芦原線`）。
駅を持たない幽霊路線ができるので落として対処した。

空港アクセス路線は揃っている: 京成成田空港線・JR成田線・東京モノレール・
京急空港線・南海空港線・名鉄空港線・JR関西空港線・仙台空港鉄道。
