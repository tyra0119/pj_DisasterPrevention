# 2026-09-08

## manual.html を書いた

アプリと同じ 4 言語（日本語 / EN / 中文 / 한국어）の使い方。→ [[製品の画面]]

中身は 12 節。何をするアプリか / 地震の前に 1 分だけ / 色帯 6 種の読み方 /
再開までの幅の読み方 / 場所の行と路線の内訳 / 出国便 / 休める場所と逃げる場所 /
地図 / 数字の根拠と限界 / 圏外のとき / 試してみる / よくある質問。

決めたこと。

- **画面と同じ色・同じ言い回しで書く。** 別の見た目にすると、画面で見た帯と
  マニュアルに並ぶ帯が同じものだと分からない。判定帯 6 種と印 7 種は
  本物と同じ CSS で並べた
- **Service Worker の shell に入れる** (v27)。回線が細るときにこそ読まれる
- **入口は設定ダイアログと画面下の 2 つ。** 設定するときが、いちばんマニュアルが要るとき
- **言語はマニュアル側だけで切り替える。** アプリの保存済み設定は読むが書き戻さない
- 「試してみる」に `?scenario=` と `?event=` のリンクを置いた。
  地震が無い日は「平常どおり」しか出ないので、これが無いと何も確かめられない

数字の根拠（高浜・翠川 2011 の表と、鉄道会社は自前の地震計で判断するという限界）は
[[コンテスト応募]] の資料と同じものを、利用者向けの言葉で書き直して載せた。
