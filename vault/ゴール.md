# ゴール

2026-09-06 に絞り直した。それまでは「帰れるのか／飛べるのか」だったが、
広すぎて実装が発散していた。

> **待つか、今夜の寝場所を確保するかを、いま決められるようにする。**

## このアプリにしかできないこと

**「運転再開の見込みは立っていません」に数字を与えること。** これだけ。

鉄道会社が見込みを出さないのは方針ではなく、出せないから。点検の内容で
復旧時間が大きく変わり、正確な数字が特定できない。だから全社が同じことを言う。

2026-08-23 の地震がまさにそれだった。02:00 発生 → 05:00 始発から運転見合わせ
→ **06:15 時点でも再開見込みが立たず**。4 時間以上、誰も「あとどれくらい」を言っていない。

そこに [[停止推定]] で幅を出せる。**この数字を出しているところは他にない。**

## このアプリでなくてもいいもの

| | 誰が出しているか |
|---|---|
| 震度・震源 | 気象庁、NHK、Yahoo!防災速報 |
| 運行情報 | 各鉄道会社。ODPT を繋いでも二番煎じ |
| 避難場所 | 国土地理院、自治体、全国避難所ガイド |

**作ってきたものの大半は他でも見られる。** 唯一のものは「あとどれくらい」だけ。
そこを軸に据える。

## なぜその決断か

大地震のあと、駅周辺のホテルは数時間で埋まる。
**1 時間目に決めるか 4 時間目に決めるかで結果が変わる。**

そして訪日外国人は、日本語のアナウンスが読めず、「点検」が何時間を意味するかも
知らず、ホテルが埋まることも知らない。**一番判断材料がない人**。

だから「あとどれくらい」に価値がある。3 時間なら待てる、6 時間なら宿を取れ、
という判断のため。

## 優先順が変わった

**上がったもの**

- **決断の形で出す。** 「5時間35分」ではなく「今夜は動けない可能性が高い」。
  時刻で出す（「最も遅くて 13:10 ごろ」）。ストレス下で引き算をさせない
- **一時滞在施設。** 帰宅困難者が一時的に休む場所。東京都と各区がオープンデータで出す。
  いま入っている指定緊急避難場所は「建物が危ないときに逃げる先」で、用途が違う
  → [[避難場所と地図]]

**下がったもの**

- **ODPT 運行情報。** 「止まっている」ことの裏取りにはなるが、それは他でも見られる。
  急ぎではない
