# 避難場所と地図

[[DisasterPrevention]] は防災情報でもあるので、電車の話だけでは足りない。
「電車は動かない」と分かった人が次に要るのは、どこへ行けばよいかの当て。

## 主役は一時滞在施設

[[ゴール]] を絞ってから、出すべきものが変わった。

- **一時滞在施設** … 帰れない人が一時的に休む場所。**こちらが主**
- **指定緊急避難場所** … 建物が危ないときや火災から逃げる先

電車が動かないと分かった人が次に要るのは、座って待てる場所。
逃げる先ではない。画面でも一時滞在施設を上に置き、
指定緊急避難場所は「危険から逃げる場所」として下に別見出しで出す。

### 全国では揃わない

一時滞在施設は自治体ごとの公開で、機械可読で出しているのは
**東京都（都立 226 件）と品川区（14 件）だけ**。区の多くは HTML か PDF。

都のデータには**座標が無く住所だけ**なので、国土地理院のジオコーダで
ビルド時に引いて同梱した（実行時に 240 回叩かせない）。
226/226 引けた。

**収録範囲の外では「近くに無い」と言わない。** 一番近い施設が 60km より遠ければ
収録範囲の外と判断して、「この地域はまだ収録できていません。近くに無いという
意味ではありません」と出す。黙って空にすると命に関わる読み違いになる。

大阪で開くとこの文言が出て、指定緊急避難場所（全国ある）はそのまま並ぶ。

### 途中で壊していた

品川区の CSV に引用符付きの住所があり、素朴に `split(',')` していたので
行がずれ、住所の途中が施設名になっていた。しかも `Number('')` が 0 になるため、
**緯度経度 0,0 の行が「有限だから妥当」として通っていた**。
引用符を読む CSV パーサに替え、日本の範囲に収まるかで検査するようにした。

## 出典を選び直した

最初に当たったのは **国土数値情報の避難施設データ (P20)**。だが使わなかった。

- **最新が 2012 年度。** 14 年前
- **非商用限定。** CC BY ではない
- 国交省自身が「最新の情報ではない場合もある」と注記している

命に関わる案内に 14 年前のデータは使わない。

代わりに **国土地理院の指定緊急避難場所データ**。市区町村が指定したものを
地理院が集約していて、現行。
https://www.gsi.go.jp/bousaichiri/hinanbasho.html

    https://cyberjapandata.gsi.go.jp/xyz/skhb04/10/{x}/{y}.geojson

**災害種別ごとにレイヤが分かれている。** 地震は `skhb04`。
洪水専用の高台を地震のときに案内しないよう、`disaster4 = 1` だけを拾う。

**ズーム 10 だけに配信されている。** 1 枚で数十 km 四方を覆うので、
居場所の周りの 9 枚を取れば足りる。**CORS 開放**なのでブラウザから直接叩ける。
同梱データを増やさずに済んだ。

属性は `name` / `address` / `disaster1`〜`disaster8`。距離を計算して近い順に 5 件。
経路は Google マップに投げる。歩き方まで自前で持つ理由がない。

## 開設しているかは確認できない

「使えることを確認できれば誘導もできる」という問いへの答えは、**できない**。

避難所の開設状況は **L アラート**（総務省の災害情報共有システム）に集約されている。
自治体が入れ、報道が受け取る。だが**一般公開のオープン API が無い**。
「全国避難所ガイド」が L アラート連携の API を出しているが、
**NDA 締結と申込のうえで鍵が発行される**形で、誰でも叩けるものではない。
呉市のように個別にオープンデータで出す自治体はあるが、全国は揃わない。

## だから「誘導」はしない

そもそも **指定緊急避難場所と指定避難所は別物**。

- **指定緊急避難場所** … 危険から逃げる先。地震では公園・広場など
- **指定避難所** … 帰れない人がしばらく滞在する場所。開設が要る

このアプリが出しているのは前者。**逃げる先であって、泊まる所ではない。**

しかも訪日外国人の場面では、**動かない方が正しいことが多い**。
日本では地震のあと一斉帰宅を抑制するよう求められている。
安全な建物の中にいるなら、まず動かない。

そこで、避難場所の一覧には 3 つを添えた。

- 「建物が危ないときや火災から逃げるときに向かう場所です」（何のための場所か）
- 「いま安全な建物の中にいるなら、まず動かないこと」（一覧より先に読ませる）
- 「開設しているかどうかは、ここでは分かりません」（一覧の後に）

**行き先を並べることと、そこへ誘導することは別。** 並べるだけにとどめる。

## 地図ライブラリを入れない

**地理院タイルを並べるだけの部品を自前で書いた** (`src/app/map.js`)。

ビルド工程が無いので、ライブラリを使うなら CDN から読むことになる。
**圏外だと読めずに地図ごと消える。地震のあとに一番効いてほしい場面で消える。**

必要なのは「震源はどっちか」「避難場所はどっちか」であって、
自由に動かせる地図ではない。タイルを並べて印を置けば足りる。
タイルが出なくても、下の一覧と距離は残る。

**幅は描いてからでないと分からない。** 文字列を組み立てる時点で 520px と
決め打ったら、341px の画面で右が切れて震源の印が画面外に出た。
先に枠だけ置き、描画後に実寸を測ってからタイルと印を入れる形にした。

縮尺は「入れたい点が全部入る」ように選ぶ。震源だけ出しても遠近が分からないので、
震源と自分の両方が入る縮尺にする。

## 震源の地図は補足

既定では畳んである。**判断に要るのは待ち時間で、震源の位置は補足**。
上に判定帯があって、その下に「地図で見る」。

出典表示（地理院タイル）は地図の右下に常時出す。
