# 運転系統の対応表

[[DisasterPrevention]] で震度を乗客の見る単位に翻訳するための写像。
数値と手順は `NOTES.md`、実装は `scripts/lib/match-lines.mjs`。

## 何が問題だったか

ODPT の運行情報は **運転系統** 単位、国土数値情報 N02 は **線路名称** 単位で、
名前が一致しない。

- ODPT「三田線」 / N02「6号線三田線」
- ODPT「山手線」は N02 の **山手線・東北線・東海道線** の 3 本にまたがる
  （N02 の山手線は品川〜新宿〜田端の 17 駅しかない）

震度は N02 側で割り当てるので、ここを繋がないと運行情報と突き合わせられない。
→ [[データ源]]

## 手書きしない

対応表を手で書くと N02 の改版で静かに腐る。改称や路線の分割が起きても、
コードは何も言わずに間違った答えを出し続ける。

**駅の並びから導く。** ODPT の駅を N02 の駅に当て、路線ごとに
「この系統の駅を何駅覆うか」で投票して、貪欲に被覆を広げる。

こうすると **被覆率** という形で壊れたことが分かる。
覆えなかった駅は捨てずに `unmatched` に残す。

## 結果

**190 / 215 系統、駅の被覆 2,092/2,131 (98.2%)。**
全駅一致 151 / 一部 13 / 不一致 26。

狙いどおり多対一が解けている。

| 系統 | N02 路線 |
|---|---|
| 山手線 (30/30) | 山手線 / 東北線 / 東海道線 |
| 京浜東北線・根岸線 (47/47) | 東北線 / 東海道線 / 根岸線 |
| 埼京線・川越線 (24/24) | 東北線 / 山手線 / 川越線 / 赤羽線 |
| 湘南新宿ライン (16/16) | 東海道線 / 山手線 / 東北線 |

空港アクセスは 京急空港線 (7/7)、成田スカイアクセス線 (4/4)、
成田線空港支線 (3/3)、東京モノレール羽田空港線 (5/6) が取れた。
`titleEn` に英語名が入っているので、訪日外国人向けの表示にそのまま使える。

## ODPT で引っかかったこと

**`odpt:Station` は 1 応答 1,000 件で頭打ち。** 全国を一度に引くと静かに切られる。
事業者ごとに引けば上限に当たらない。1,449 → 2,130 駅になった。

**`odpt:stationOrder` を公開していない事業者が多い。** 215 系統中 62 系統しか持っていない。
ただし `odpt:Station` の各駅が `odpt:railway` を持つので、そこから駅の集合を復元できる。
照合は集合しか見ないので順序が無くても困らない。これで 62 → 190 系統になった。

**「ケ」と「ヶ」で割れる。** 市ケ谷/市ヶ谷、阿佐ケ谷、霞ケ関、茅ケ崎、姉ケ崎…
未一致の最大の原因だった。ほかに 麴町/麹町（異体字）と、
明治神宮前〈原宿〉のような別称の併記。正規化で吸収した。

## 曖昧なら当てない

ODPT が 1 駅しか公開していない系統が 35 件あった（多くは接続駅だけ）。
その駅を含む N02 路線が 1 本しかないなら曖昧さが無いので拾う（10 件解決）。

**複数あるなら当てない。** 仙台（仙石線・仙山線・東西線がどれも仙台 1 駅だけ）、
塩尻（中央本線）、高松（瀬戸大橋線）など 26 件は未対応のまま残す。
誤った路線を「揺れている」と言う方が、分からないと言うより悪い。

仙台空港線もこれで落ちている（ODPT が名取 1 駅しか出していない）。
空港アクセスとしては痛いので、必要なら手で足す。→ [[宿題]]

## 鍵の置き場所

対応表の生成は **ビルド時**。鍵は手元の `.env.local` に置いたままでよく、
生成物 `data/line-map.json` にも Pages にも載らない（確認済み）。

`ODPT_KEY` は `api.odpt.org`、`ODPT_CHALLENGE_KEY` は `api-challenge.odpt.org` と
当たり先が違い、配信されるデータも違う。両方から取って統合している
（94 + 214 系統 → 重複を除いて 215）。

実行時に運行情報を取りに行く部分は別問題。→ [[宿題]]

## 系統への合成

`src/rail/systems.js` が N02 路線ごとの結果を系統に畳む。**最大を取る。**
事業者が区間ごと止めるからで、[[設計判断]] の路線と同じ理由。

対応表が系統の全駅を覆えていない場合は `partial` を立てる。
覆えていない区間で強く揺れていても気づけないので、結論を弱める材料にする。
