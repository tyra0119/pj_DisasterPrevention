# DisasterPrevention

訪日外国人向けの単体 Web アプリ。地震発生から 30 分〜数時間の
**「帰れるのか／飛べるのか」** に答える。

震度の数値ではなく、待つべきか動くべきかの判断材料に翻訳して出す。
遅延レーダーとは別アプリで、入口だけリンクする。

## 決めてあること

- **待つか、今夜の寝場所を確保するかを、いま決められるようにする** → [[ゴール]]
- 対象は訪日外国人。狙う時間帯は発災 30 分〜数時間
- 処理順は 震度分布 → 路線への割り当て → 停止推定 → ODPT 運行情報で確定
- 事前登録は宿・出国便・言語。URL クエリで共有可能に
- ODPT の航空データ（JAL/ANA 発着）を空港アクセスと繋ぐのが差別化点
- Service Worker でオフライン対応、最終取得時刻を必ず表示
- プッシュ通知は前提にしない
- GitHub Pages でリポジトリ直下をそのまま配信（遅延レーダーと同じ）。ビルドもサーバも持たない
