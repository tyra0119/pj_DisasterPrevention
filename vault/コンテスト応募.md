# コンテスト応募

2026-09-06、公共交通オープンデータチャレンジ2026 に応募すると決めた。
書類はリポジトリの `公共交通オープンデータチャレンジ2026/` に置いた。

## なぜ出せるのか

応募条件は「公共交通オープンデータセンターのデータを使うこと」。
本作は `odpt:Railway` / `odpt:Station` で運転系統の対応表を作り、
`odpt:TrainInformation` で推定を終わらせている。→ [[運転系統の対応表]] [[運行情報で推定を終わらせる]]

審査基準は 社会課題解決 / データ活用のインパクト / 技術的完成度 / UI・UX。
[[ゴール]] で絞った「見込みは立っていませんに数字を与える」がそのまま社会課題の話になる。

## 日程

応募期間 2026-10-01 〜 **2027-01-11 23:59**。一次審査 2027-01-23〜24。表彰式 2027-02-20。
フォームは 10/1 公開なので、項目は公開後に下書きと突き合わせる。
**提出後は説明文を直せない。**

## 応募前に決着させること

**鍵の公開をやめる。** API 利用ガイドラインは「アクセストークンを第三者に開示しない」。
テスト用途と割り切って `endpoints.js` に貼った鍵 (2026-09-06) は、応募条件「規約遵守」に抵触する。
`proxy/worker.js` を置いて `ODPT_KEYS` を空に戻し、鍵は再発行する。→ [[宿題]]

そのほか: 出典表示に国土地理院・東京都を足す、仙台空港線の対応表、README の英語併記。

## 素材 (2026-09-06)
